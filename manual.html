Workflow assist 사용 설명서

논문과 보고서에 바로 넣을 수 있는 워크플로우·플로우차트를 그리는 도구입니다. 그리드, 간격, 연결선 모양 같은 "규격"은 자동으로 지켜 주고, 위치·크기·색·글꼴은 원하는 대로 바꿀 수 있습니다.

Workflow assist란

Nature, Cell, Science 같은 학술지 그림의 관례를 기본값으로 삼습니다: Helvetica/Arial 글꼴, 약 1 pt의 가는 선, 작은 채움 화살표, 절제된 연한 색, 패널 문자(a, b, c)가 붙은 단계 밴드. 이 기본값 위에서 자유롭게 편집하되, 새로 놓는 요소는 항상 격자와 표준 간격에 맞춰 정렬되므로 결과물이 흐트러지지 않습니다.

5분 만에 첫 그림

  1. 왼쪽 툴바에서 둥근 사각형(R)을 누르고 캔버스를 클릭합니다. 바로 글자를 입력하고 Enter로 확정합니다(줄바꿈은 Shift+Enter).
  2. 노드 위에 마우스를 올리면 네 변에 작은 원(포트)이 나타납니다. 오른쪽 포트를 잡고 빈 곳으로 드래그하면 표준 간격만큼 떨어진 새 노드가 만들어지고 연결됩니다. 이 동작을 반복하면 정렬된 흐름이 완성됩니다.
  3. 분기가 필요하면 마름모(D)를 놓고 포트를 다른 노드로 드래그해 연결한 뒤, 연결선을 더블클릭해 Yes/No 라벨을 씁니다.
  4. 오른쪽 패널에서 채움색을 고르고, 필요하면 단계 밴드로 구간을 묶습니다.
  5. 내보내기 → SVG로 저장하면 원고 편집기나 Illustrator, PowerPoint에서 그대로 사용할 수 있습니다.

도형과 텍스트

도형 종류: 둥근 사각형(프로세스), 사각형, 시작/종료(알약형), 마름모(판단), 타원, 평행사변형(입출력), 원통(데이터), 육각형(준비), 화살 블록(단계), 삼각형, 별(강조), 문서, 클라우드(외부 시스템). 선택한 뒤 오른쪽 패널의 도형 그리드에서 언제든 다른 모양으로 바꿀 수 있습니다.

  • 이동: 드래그. 다른 노드의 중심선·모서리와 맞으면 분홍 가이드가 나타나며 자석처럼 붙습니다. 자유롭게 놓으려면 Alt를 누른 채 드래그합니다.
  • 크기: 선택 후 8개의 핸들을 드래그하거나 패널의 W/H에 숫자를 입력합니다.
  • 글자: 더블클릭(또는 Enter)으로 편집. 패널에서 크기·굵게·왼쪽 정렬(목록형 텍스트에 유용)을 설정합니다.
  • 텍스트(T): 도형 없이 글자만 놓습니다. 패널 문자 a, b나 그림 제목에 씁니다.
  • 복제 Ctrl+D, 삭제 Delete, 미세 이동 방향키(Shift로 10배).

연결선

만드는 방법은 세 가지입니다. ① 노드의 포트를 다른 노드로 드래그, ② C 도구로 출발 노드 → 도착 노드 클릭, ③ 손그림(P)으로 두 노드 사이에 선을 긋기.

  • 경로: 직각(기본)·직선·곡선. 직각 경로는 양쪽이 대칭이 되도록 중간에서 꺾이며, 선을 선택하면 나타나는 둥근 핸들을 드래그해 꺾이는 위치를 옮길 수 있습니다. "자동 경로"를 누르면 다시 자동으로 돌아갑니다.
  • 화살표: 시작·끝 각각 없음 / 채움 / 열림 / 점 중 선택. 방향 반전으로 출발·도착을 바꿉니다.
  • 재연결: 선을 선택하면 양 끝에 사각 핸들이 생깁니다. 다른 노드로 끌어다 놓거나, 빈 곳에 놓아 자유 끝점으로 만들 수 있습니다.
  • 라벨·점선·색·굵기: 패널에서 설정. 여러 선을 함께 선택하면 한 번에 적용됩니다.
  • 길이 통일: 여러 연결선을 선택하고 "길이 통일 (px)"에 값을 넣어 적용하면 각 도착 노드가 출발 노드로부터 같은 거리로 이동합니다. "직선화"를 켜면 중심선까지 맞춰 꺾임이 사라집니다.
선이 미세하게 꺾일 때 두 노드의 중심 높이가 몇 px 다르기 때문입니다. 한쪽을 살짝 드래그해 분홍 가이드에 붙이거나, 두 노드를 선택해 "세로 중앙" 정렬을 누르세요.

정렬 · 간격 · 그룹

Shift+클릭 또는 빈 곳에서 드래그(영역 선택)로 여러 요소를 고릅니다. 2개 이상 선택하면 패널에 정렬 도구가 나타납니다.

  • 정렬 왼쪽 / 가로 중앙 / 오른쪽 / 위 / 세로 중앙 / 아래
  • 균등 분배 현재 양 끝은 그대로 두고 사이 간격만 같게
  • 간격 고정 입력한 px 간격으로 순서대로 재배치 — 노드 사이 연결선 길이가 모두 같아집니다
  • 크기 맞춤 첫 번째로 선택한 요소의 너비·높이로 통일
  • 그룹 Ctrl+G — 이후 하나를 클릭하면 그룹 전체가 선택되어 함께 이동·삭제됩니다. 연결선도 그룹에 넣을 수 있습니다. 해제는 Ctrl+Shift+G.

단계 밴드 · 패널 라벨

밴드는 여러 노드를 한 구간으로 묶는 연한 배경입니다. 툴바의 점선 사각형 아이콘으로 놓고 크기를 조절하세요. 밴드를 옮기면 안에 있는 노드가 함께 이동합니다. 밴드 안의 빈 곳에서 드래그하면 밴드가 아니라 안쪽 요소들이 영역 선택됩니다(밴드 자체는 테두리 근처나 라벨 부분을 잡아 옮깁니다).

  • 라벨: 첫 글자 뒤에 공백 두 칸을 넣으면(a Sample collection) 앞 글자가 패널 문자로 굵고 크게 표시됩니다.
  • 모서리: 각 / 8 / 16 / 28 px 중 선택. 테두리: 없음 / 실선 / 점선.
  • 스윔레인: 세로로 긴 밴드를 나란히 놓으면 담당자·부서별 프로세스(보고서용 예제 "업무 승인 프로세스" 참고)가 됩니다.

손그림 인식

P를 누르고 마우스나 펜으로 대충 그리면 규격 도형으로 바뀝니다. 닫힌 모양은 모서리 수와 기울기에 따라 사각형·마름모·타원·알약형으로, 열린 선은 연결선으로 인식됩니다. 두 노드 사이에 선을 그으면 그 둘을 잇는 연결선이 됩니다.

인식 직후 나타나는 작은 팝업에서 다른 도형으로 바꾸거나, 마지막 아이콘으로 손그림 원본을 그대로 남길 수 있습니다. 인식은 규칙 기반이라 복잡한 그림은 정확하지 않을 수 있습니다.

이미지 · 아이콘 라이브러리

툴바의 이미지 아이콘(또는 패널의 "이미지 · 아이콘 업로드")으로 PNG / JPG / SVG를 올리면 내 이미지 도형에 저장되고, 이후엔 클릭 → 캔버스 클릭으로 언제든 배치할 수 있습니다. 배치된 이미지는 일반 노드처럼 포트로 연결하고, 크기를 조절하고, 더블클릭으로 아래에 캡션을 달 수 있습니다.

  • 단색화: 회색조로 바꿔 논문 그림의 톤에 맞춥니다. 테두리 상자: 다른 노드와 같은 테두리로 감쌉니다.
  • 큰 사진은 자동으로 640 px 이하로 줄여 저장합니다. 라이브러리에서 지우려면 Shift+클릭.
  • 라이브러리는 이 브라우저에만 저장됩니다. 그림 자체는 JSON/SVG에 이미지가 포함되어 내보내지므로 다른 PC에서도 열립니다.

색 팔레트

기본 팔레트는 색약·흑백 인쇄에서도 구분되는 Okabe–Ito 계열을 연하게 조정한 9색이며, 연한 채움(검은 글자)과 진한 채움(흰 글자) 두 줄로 제공됩니다. 팔레트 끝의 +를 누르면 원하는 색을 추가할 수 있고, 추가한 색은 연한/진한/테두리 줄 모두에 자동으로 나타나며 이 브라우저에 저장됩니다. 지우려면 Shift+클릭.

권장 한 그림에 강조색은 2~3개까지만, 나머지는 흰색·회색으로. 색은 의미(데이터 / 처리 / 판단 / 결과)에만 대응시키면 읽기 쉽습니다.

아무것도 선택하지 않은 상태에서 오른쪽 패널의 값이 그림 전체에 적용됩니다.

내보내기 · 저장

  • SVG: 벡터. 학술지 투고, Illustrator/Inkscape 편집, Word·PowerPoint 삽입에 가장 좋습니다. 격자·선택 표시는 포함되지 않습니다.
  • PNG: 캔버스의 3배 해상도(너비 1200 px 캔버스 → 3600 px, 30 cm 폭 기준 약 300 dpi). 시스템 글꼴(Arial 등)로 렌더링됩니다.
  • JSON: 편집 가능한 원본. 다른 PC나 동료에게 전달할 때 사용하고, 파일 → JSON 불러오기로 엽니다.
  • SVG 코드 복사: 다운로드가 막힌 환경에서 클립보드로 복사해 .svg 파일로 저장할 수 있습니다.
  • 자동 저장: 작업은 브라우저에 자동 저장되어 다음에 열면 이어집니다. 브라우저 데이터를 지우면 사라지므로 중요한 그림은 JSON으로 보관하세요.

자주 묻는 질문

학술지에 낼 때 권장 설정은?

Nature 프리셋, 글자 크기 11~12 px, 캔버스 너비 1200 px(2단 폭 그림 기준)로 그린 뒤 SVG로 내보내면 됩니다. 대부분의 학술지는 벡터(SVG/PDF/EPS)를 선호하며, 래스터가 필요하면 PNG 3배로 충분합니다.

한글이 포함된 그림을 PNG로 내보내면 글꼴이 달라요.

PNG는 브라우저 내부에서 시스템 글꼴로 그립니다. 글꼴을 정확히 유지하려면 SVG로 내보낸 뒤 Illustrator·Inkscape 등에서 PNG/PDF로 변환하세요.

연결선이 다른 노드를 가로질러요.

선을 선택하고 둥근 핸들을 드래그해 꺾이는 위치를 옮기거나, 경로를 "곡선"으로 바꾸거나, 출발·도착 포트를 다른 변으로 재연결하세요(끝 핸들을 노드의 원하는 변 근처에 놓으면 그 변의 포트에 붙습니다).

여러 그림을 관리하고 싶어요.

그림마다 JSON으로 저장해 두고 필요할 때 불러오세요. 자동 저장은 마지막 작업 하나만 보관합니다.
