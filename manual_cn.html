Workflow-assist 使用指南

一款用来绘制可直接放入论文和报告的工作流程图与流程图的工具。网格、间距、连接线形状等"规范"会自动保持，而位置、大小、颜色和字体都可以随意更改。

关于界面语言 编辑器的按钮和菜单目前只有韩语。为了便于在界面上找到对应功能，本指南会在中文名称后用灰色标注韩语原文，例如 导出 (내보내기)。

什么是 Workflow-assist

它以 Nature、Cell、Science 等期刊插图的惯例作为默认值：Helvetica/Arial 字体、约 1 pt 的细线、小型实心箭头、克制的浅色，以及带面板字母（a、b、c）的阶段带。你可以在这些默认值之上自由编辑，而新放置的元素总会对齐网格和标准间距，因此成品不会显得凌乱。

5 分钟画出第一张图

  1. 在左侧工具栏点击 圆角矩形（R），再点击画布。直接输入文字，按 Enter 确认（换行用 Shift+Enter）。
  2. 把鼠标移到节点上，四条边上会出现小圆点（端口）。抓住右侧端口 拖到空白处，就会在标准间距处生成一个新节点并自动连接。重复此操作即可完成整齐的流程。
  3. 需要分支时，放置一个 菱形（D），把它的端口拖到另一个节点上连接，然后双击连接线输入 Yes/No 标签。
  4. 在右侧面板中选择填充颜色，需要时用 阶段带 把一段流程框在一起。
  5. 用 导出 → SVG (내보내기 → SVG) 保存后，即可直接在稿件编辑器、Illustrator 或 PowerPoint 中使用。

图形与文字

13 种图形：圆角矩形（处理）、矩形、开始/结束（胶囊形）、菱形（判断）、椭圆、平行四边形（输入/输出）、圆柱（数据）、六边形（准备）、箭头块（阶段）、三角形、星形（强调）、文档、云形（外部系统）。选中后，可随时在右侧面板的图形网格中换成其他形状。

  • 移动：拖动。与其他节点的中心线或边缘对齐时，会出现粉色参考线并像磁铁一样吸附。按住 Alt 拖动即可自由放置。
  • 大小：选中后拖动 8 个控制点之一，或在面板的 W/H 中输入数值。
  • 文字：双击（或按 Enter）编辑。在面板中设置字号、加粗、左对齐（适合列表式文字）和 文字颜色 (글자 색)。
  • 文字工具（T）：不带图形、只放置文字，用于面板字母 a、b 或图标题。
  • 复制 Ctrl+D，删除 Delete，微调 用方向键（按住 Shift 为 10 倍）。

连接线

创建方法有三种：① 把节点的端口拖到另一个节点上；② 用 C 工具依次点击起点节点和终点节点；③ 用手绘工具（P）在两个节点之间画一条线。

  • 路径 (경로)：直角（默认）(직각)、直线 (직선)、曲线 (곡선)。直角路径会在中间折弯，使两侧对称；选中线条后拖动出现的圆形控制点可以移动折弯位置。点击 自动路径 (자동 경로) 可恢复自动布线。
  • 箭头：起点和终点可分别选择 无 / 实心 / 空心 / 圆点。反转方向 (방향 반전) 可交换起点和终点。
  • 重新连接：选中线条后两端会出现方形控制点。可将其拖到其他节点上，或放到空白处成为自由端点。
  • 标签、虚线、颜色、线宽：在面板中设置。同时选中多条线可一次性应用。
  • 统一长度 (길이 통일)：选中多条连接线，输入 px 数值并应用，每个终点节点都会移动到距起点节点相同的距离。打开 拉直 (직선화) 后，中心线也会对齐，折弯随之消失。
线条出现细小折弯时 这是因为两个节点的中心高度相差几个像素。把其中一个稍微拖动，让它吸附到粉色参考线上，或者同时选中两者后点击"垂直居中"对齐。

对齐 · 间距 · 编组

用 Shift+点击，或在空白处拖动（框选）来选择多个元素。选中两个及以上时，面板中会出现对齐工具。

  • 对齐 左 / 水平居中 / 右 / 上 / 垂直居中 / 下
  • 水平均分 · 垂直均分 (가로 균등 · 세로 균등) — 保持两端不动，只让中间的间距相等
  • 固定间距 (간격 고정) — 按输入的像素间距依次重新排列（"水平应用" (가로 적용) / "垂直应用" (세로 적용)），节点之间的连接线长度将全部相同
  • 统一宽度 · 统一高度 (너비 길이 맞춤 · 높이 길이 맞춤) — 以 第一个选中的图形 的宽度或高度为准，调整其余图形
  • 编组 Ctrl+G — 之后点击其中一个即可选中整组，一起移动和删除。连接线也可以加入编组。取消编组用 Ctrl+Shift+G。

阶段带 · 面板标签

阶段带是把多个节点归为一段的浅色背景。用工具栏中的虚线矩形图标放置并调整大小。移动阶段带时，其中的节点会一起移动。在阶段带内的空白处拖动时，框选的是其中的元素而不是阶段带本身（要移动阶段带，请抓住边框附近或标签部分）。

  • 标签：在第一个字符后输入两个空格（a Sample collection），该字符就会作为面板字母以加粗放大的形式显示。
  • 背景：从填充调色板中选择。圆角：直角 / 8 / 16 / 28 px。边框：无 / 实线 / 虚线。
  • 泳道：把竖长的阶段带并排放置，就能画出按负责人或部门划分的流程图（参见报告用模板"审批流程"）。

手绘识别

按 P 后用鼠标或手写笔随手画，笔画就会变成规范图形。闭合的形状会根据角的数量和倾斜度识别为矩形、菱形、椭圆或胶囊形；开放的线条会识别为连接线。在两个节点之间画线，就会生成连接它们的连接线。

识别后立即出现的小弹窗中，可以切换为其他图形（处理、矩形、开始/结束、判断、椭圆、连接线），或用最后一个图标保留手绘原样。识别基于规则，复杂的图形可能识别不准确，六边形、星形等图形不会被识别。

图片 · 图标库

通过工具栏的图片图标（或面板中的"上传图片 · 图标" (이미지 · 아이콘 업로드)）上传 PNG / JPG / SVG 后，会保存到 我的图片图形 (내 이미지 도형)，之后点击它再点击画布即可随时放置。放置的图片和普通节点一样，可以用端口连接、调整大小，双击即可在下方添加说明文字。

  • 去除背景 (배경 제거)：选中图片后点击强度 弱 / 中 / 强 (약 / 중 / 강) 之一，与边缘相连的纯色背景（如白色）就会变为透明。不满意时可换一个强度，或点击 原图 (원본) 恢复。去除背景后的版本可以通过"将此版本添加到图库" (이 버전을 라이브러리에 추가) 另行保存。像照片那样背景不均匀的图片效果不佳。
  • 单色化 (단색화)：转为灰度，与论文插图的色调保持一致。边框 (테두리 상자)：用与其他节点相同的边框包围图片。
  • 较大的照片会自动缩小到 640 px 以内再保存。要从图库中删除，请 Shift+点击。
  • 图库只保存在当前浏览器中。图形本身在导出为 JSON/SVG 时会包含图片，因此在其他电脑上也能打开。

调色板

选中图形后，面板中会分别显示 填充 (채움)、边框 (테두리) 和 文字颜色 (글자 색) 调色板。默认颜色基于 Okabe–Ito 配色调整而来，色觉障碍读者和黑白印刷也能清楚区分。把鼠标移到颜色上，会显示其名称和 HEX 代码（例如 #2F6DB5）。

  • 填充：一行共 34 种颜色 — 白色、3 级灰色，以及 10 种色相（灰、蓝、青、绿、黄、橙、红、紫、藏青、粉）的浅 / 中 / 深三个层级。选择深色填充时，文字会自动变为白色。
  • 边框：无（显示为虚线空格）和 10 种颜色。"无"适用于所有图形。
  • 文字颜色：白色和 10 种颜色。自己选择的文字颜色优先于自动白色。
  • 添加颜色：点击任一调色板末尾的 +，会出现 24 种推荐颜色、取色器和 HEX 输入框（#RRGGBB）。添加的颜色 只进入该调色板，并保存在当前浏览器中。要删除，请 Shift+点击。
  • 要更改整张图的默认线条和文字颜色，请在未选中任何内容时使用 图形规范 → 默认线条 · 文字颜色 (그림 규격 → 기본 선 · 텍스트 색)。
建议 一张图中的强调色最多用 2~3 种，其余用白色或灰色。让颜色只对应含义（数据 / 处理 / 判断 / 结果），图会更易读。

图形规范（预设）

未选中任何内容时，右侧面板中的数值会应用到整张图。

预设特点
NatureHelvetica · 1.2 px 线条 · 4 px 圆角 · 浅色阶段带。适用于大多数期刊
Cell稍粗的线条（1.6 px）和更圆的圆角（8 px）。适合大胆用色的图
Mono直角、细线、仅用灰色。适合黑白印刷和报告正文

字体（Helvetica/Arial、Noto Sans KR、IBM Plex Sans KR、Times New Roman）、默认字号、线宽、圆角半径、箭头大小、默认间距（gap）、网格间距和画布尺寸都可以单独调整。为单个元素设置的颜色或字号优先于图形规范。

导出 · 保存

  • SVG：矢量格式。最适合期刊投稿、在 Illustrator/Inkscape 中编辑，以及插入 Word 或 PowerPoint。不包含网格和选中标记。
  • PNG：画布的 3 倍分辨率（宽 1200 px 的画布 → 3600 px，按 30 cm 宽约为 300 dpi）。使用系统字体（Arial 等）渲染。
  • JSON：可编辑的原始文件。用于转移到其他电脑或分享给同事，通过 文件 → 打开 JSON (파일 → JSON 불러오기) 打开。
  • 复制 SVG 代码 (SVG 코드 복사)：在无法下载的环境中，可复制到剪贴板并保存为 .svg 文件。
  • 自动保存：作品会自动保存在浏览器中，下次打开时继续。清除浏览器数据会导致丢失，重要的图请保存为 JSON。

嵌入其他网站

Workflow-assist 无需构建，仅凭一个 index.html 文件即可运行，因此可以用 iframe 嵌入其他网站，并通过 JavaScript API（postMessage）载入和取出文档或获取 SVG。与网站使用的技术（React、Vue 等）无关。

  • 可运行的示例：embed-example.html（在同一文件夹中打开即可运行）
  • API 规范和文档（JSON）格式：DEVELOPER.md（韩语）

常见问题

投稿期刊时推荐什么设置？

使用 Nature 预设、11~12 px 字号、1200 px 画布宽度（按双栏宽度插图）绘制，然后导出为 SVG 即可。大多数期刊偏好矢量格式（SVG/PDF/EPS）；如需位图，3 倍 PNG 已足够。

导出 PNG 后字体变了。

PNG 是在浏览器内部用系统字体绘制的。要准确保留字体，请先导出 SVG，再在 Illustrator、Inkscape 等软件中转换为 PNG/PDF。

连接线穿过了其他节点。

选中线条后拖动圆形控制点移动折弯位置，或把路径改为"曲线"，或把起点/终点端口重新连接到另一条边（把端点控制点放到节点目标边附近，就会吸附到该边的端口）。

我想管理多张图。

把每张图都保存为 JSON，需要时再打开。自动保存只保留最近一次的作品。

我想转移到其他电脑或浏览器。

用 导出 → JSON 保存图形，在新环境中通过 文件 → 打开 JSON 打开。添加的颜色和图片库按浏览器分别保存，不会随之转移（放置在图中的图片包含在 JSON 中）。
