Workflow-assist User Guide

A tool for drawing workflows and flowcharts that are ready to drop into papers and reports. It keeps the "rules" — grid, spacing, connector shape — automatically, while letting you change position, size, color and font however you like.

Interface language The editor is available in English and Korean — switch with the globe button in the top bar. It starts in English unless your browser is set to Korean. For anyone using the Korean interface, the Korean label is shown in grey after each feature name, e.g. Export (내보내기).

What is Workflow-assist

Its defaults follow the conventions of figures in journals such as Nature, Cell and Science: Helvetica/Arial type, thin lines of about 1 pt, small filled arrowheads, restrained light tints, and phase bands with panel letters (a, b, c). You can edit freely on top of these defaults, but every new element snaps to the grid and the standard spacing, so the result never gets messy.

Your first figure in 5 minutes

  1. Click Rounded rectangle (R) in the left toolbar, then click on the canvas. Type the text right away and press Enter to confirm (Shift+Enter for a new line).
  2. Hover over a node and small circles (ports) appear on its four sides. Grab the right port and drag it to an empty spot: a new node is created at the standard distance and connected. Repeat to build a neatly aligned flow.
  3. For a branch, place a Diamond (D), drag its port to another node, then double-click the connector to type a Yes/No label.
  4. Pick a fill color in the right panel and, if needed, group a section with a Phase band.
  5. Save with Export → SVG (내보내기 → SVG) and use it as-is in your manuscript editor, Illustrator or PowerPoint.

Shapes and text

13 shapes: rounded rectangle (process), rectangle, start/end (pill), diamond (decision), ellipse, parallelogram (input/output), cylinder (data), hexagon (preparation), chevron (phase), triangle, star (emphasis), document, cloud (external system). After selecting a shape you can switch it to another at any time from the shape grid in the right panel.

  • Move: drag. When it lines up with another node's center line or edge, a pink guide appears and it snaps like a magnet. Hold Alt while dragging to place it freely.
  • Resize: drag one of the 8 handles, or type numbers into W/H in the panel.
  • Text: double-click (or Enter) to edit. In the panel, set font size, bold, left alignment (useful for bullet-style text) and text color (글자 색).
  • Text tool (T): places text without a shape — for panel letters a, b or a figure title.
  • Duplicate Ctrl+D, delete Delete, nudge with the arrow keys (Shift for 10×).

Connectors

There are three ways to create one: ① drag a node's port onto another node, ② use the C tool and click the start node, then the end node, ③ draw a line between two nodes with the sketch tool (P).

  • Route (경로): orthogonal (default) (직각), straight (직선), curved (곡선). Orthogonal routes bend in the middle so both sides are symmetric; select the line and drag the round handle to move the bend. Auto route (자동 경로) restores the automatic layout.
  • Arrowheads: for the start and the end separately — none / filled / open / dot. Reverse (방향 반전) swaps start and end.
  • Reconnect: a selected line shows square handles at both ends. Drop one onto another node, or onto empty space to make a free endpoint.
  • Label, dashed, color, width: set in the panel. Select several lines to apply to all at once.
  • Equalize length (길이 통일): select several connectors, enter a value in px and apply — each end node moves to the same distance from its start node. With Straighten (직선화) on, center lines are aligned too, removing the bends.
When a line has a tiny kink the two nodes' centers differ by a few px. Drag one slightly until it snaps to the pink guide, or select both and click the vertical center alignment.

Align · spacing · groups

Select several elements with Shift+click or by dragging on empty space (marquee selection). With two or more selected, alignment tools appear in the panel.

  • Align left / horizontal center / right / top / vertical center / bottom
  • Distribute H · Distribute V (가로 균등 · 세로 균등) — keeps the two outer items and equalizes the gaps between them
  • Fixed gap (간격 고정) — rearranges items in order with the gap you enter ("Apply H" (가로 적용) / "Apply V" (세로 적용)); all connectors between the nodes end up the same length
  • Match width · Match height (너비 길이 맞춤 · 높이 길이 맞춤) — sets the others to the width or height of the first selected shape
  • Group Ctrl+G — afterwards, clicking one member selects the whole group so it moves and deletes together. Connectors can be grouped too. Ungroup with Ctrl+Shift+G.

Phase bands · panel labels

A band is a light background that groups several nodes into one section. Place it with the dashed-rectangle icon in the toolbar and resize it. Moving a band moves the nodes inside it. Dragging on empty space inside a band selects the elements inside rather than the band (to move the band itself, grab it near its border or its label).

  • Label: put two spaces after the first character (a Sample collection) and that character is shown large and bold as a panel letter.
  • Background: choose from the fill palette. Corners: square / 8 / 16 / 28 px. Border: none / solid / dashed.
  • Swimlanes: tall bands placed side by side make a process diagram by person or department (see the report template "Approval process").

Sketch recognition

Press P and draw roughly with a mouse or pen; the stroke turns into a standard shape. Closed shapes are recognized as rectangle, diamond, ellipse or pill depending on the number of corners and their angles; open strokes become connectors. A line drawn between two nodes becomes a connector joining them.

In the small popup that appears right after recognition, you can switch to another shape (process, rectangle, start/end, decision, ellipse, connector) or keep the original sketch with the last icon. Recognition is rule-based, so complex drawings may not be recognized accurately, and shapes like hexagons or stars are not recognized.

Image & icon library

Upload a PNG / JPG / SVG with the image icon in the toolbar (or "Upload image · icon" (이미지 · 아이콘 업로드) in the panel). It is saved to My image shapes (내 이미지 도형) and can be placed any time: click it, then click on the canvas. A placed image behaves like a normal node — connect it with ports, resize it, and double-click to add a caption below it.

  • Remove background (배경 제거): select the image and click a strength — low / medium / high (약 / 중 / 강). A solid background (such as white) connected to the edges becomes transparent. If you don't like the result, try another strength or go back with Original (원본). The background-free version can be saved separately with "Add this version to the library" (이 버전을 라이브러리에 추가). Uneven backgrounds such as photos are not removed well.
  • Monochrome (단색화): converts to grayscale to match the tone of a paper figure. Border box (테두리 상자): wraps the image in the same border as other nodes.
  • Large photos are automatically downscaled to 640 px or less. Shift+click removes an item from the library.
  • The library is stored in this browser only. Figures themselves embed their images when exported to JSON/SVG, so they open on other computers too.

Color palettes

When a shape is selected, the panel shows separate palettes for Fill (채움), Border (테두리) and Text color (글자 색). The default colors are adapted from the Okabe–Ito palette, which stays distinguishable for color-blind readers and in black-and-white print. Hover over a color to see its name and HEX code (e.g. #2F6DB5).

  • Fill: 34 colors in one row — white, 3 greys, and light / medium / dark versions of 10 hues (grey, blue, teal, green, yellow, orange, red, purple, navy, pink). Choosing a dark fill turns the text white automatically.
  • Border: None (shown as a dashed empty swatch) plus 10 colors. "None" works for every shape.
  • Text color: white plus 10 colors. A text color you pick yourself takes priority over the automatic white.
  • Adding colors: click + at the end of any palette to get 24 suggested colors, a color picker and a HEX field (#RRGGBB). An added color goes into that palette only and is saved in this browser. Shift+click removes it.
  • To change the default line and text color for the whole figure, select nothing and use Figure style → Default line · text color (그림 규격 → 기본 선 · 텍스트 색).
Recommendation Use at most 2–3 accent colors per figure and keep the rest white or grey. Figures are easiest to read when colors map only to meaning (data / processing / decision / result).

Figure style (presets)

With nothing selected, the values in the right panel apply to the whole figure.

PresetCharacter
NatureHelvetica · 1.2 px lines · 4 px corners · light bands. Safe for most journals
CellSlightly heavier lines (1.6 px) and rounder corners (8 px). For figures that use color boldly
MonoSquare corners, thin lines, greys only. For black-and-white print and report body text

You can adjust the font (Helvetica/Arial, Noto Sans KR, IBM Plex Sans KR, Times New Roman), default font size, line width, corner radius, arrowhead size, default gap, grid spacing and canvas size individually. Colors or font sizes given to individual elements take priority over the figure style.

Export · saving

  • SVG: vector. Best for journal submission, editing in Illustrator/Inkscape, and inserting into Word or PowerPoint. The grid and selection marks are not included.
  • PNG: 3× the canvas resolution (a 1200 px canvas → 3600 px, about 300 dpi at 30 cm wide). Rendered with system fonts (Arial etc.).
  • JSON: the editable source. Use it to move work to another computer or share it with colleagues; open it with File → Open JSON (파일 → JSON 불러오기).
  • Copy SVG code (SVG 코드 복사): where downloads are blocked, copy to the clipboard and save as an .svg file.
  • Auto-save: your work is saved in the browser automatically and restored next time. Clearing browser data erases it, so keep important figures as JSON.

Embedding in other sites

Workflow-assist runs from a single index.html with no build step, so you can put it into another website with an iframe and use the JavaScript API (postMessage) to load and retrieve documents or get SVG output. It works regardless of the site's technology (React, Vue, etc.).

  • Working example: embed-example.html (works when opened from the same folder)
  • API reference and document (JSON) format: DEVELOPER.md (in Korean)

FAQ

What settings do you recommend for journal figures?

Draw with the Nature preset, 11–12 px text and a 1200 px canvas width (for a double-column figure), then export to SVG. Most journals prefer vector formats (SVG/PDF/EPS); if a raster image is required, 3× PNG is enough.

The font looks different when I export to PNG.

PNG is drawn inside the browser with system fonts. To keep the exact font, export to SVG and convert it to PNG/PDF in Illustrator, Inkscape or similar.

A connector crosses another node.

Select the line and drag the round handle to move the bend, change the route to "curved", or reconnect the start/end to a different side (drop the end handle near the side you want and it attaches to that side's port).

How do I manage several figures?

Save each figure as JSON and open it when needed. Auto-save keeps only the most recent work.

How do I move my work to another computer or browser?

Save the figure with Export → JSON and open it in the new environment with File → Open JSON. Added colors and the image library are stored per browser and do not move with it (images placed in a figure are included in its JSON).
