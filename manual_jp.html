Workflow-assist ユーザーガイド

論文やレポートにそのまま載せられるワークフロー図・フローチャートを描くツールです。グリッド、間隔、コネクタの形といった「規格」は自動で守り、位置・サイズ・色・フォントは自由に変えられます。

画面の言語について エディタの画面は英語と韓国語に対応しています（上部バーの地球アイコンで切り替え。日本語の画面はまだありません）。このガイドでは、画面上で見つけやすいように日本語名の後に英語と韓国語の表記を灰色で添えています（例：書き出し (Export / 내보내기)）。

Workflow-assist とは

Nature、Cell、Science などの学術誌の図の慣例を初期値にしています：Helvetica/Arial フォント、約 1 pt の細い線、小さな塗りつぶし矢印、控えめな淡い色、パネル文字（a、b、c）付きのフェーズバンド。この初期値の上で自由に編集できますが、新しく置く要素は常にグリッドと標準間隔に揃うので、仕上がりが乱れません。

5分で最初の図

  1. 左ツールバーの 角丸長方形（R）を押し、キャンバスをクリックします。そのまま文字を入力し、Enter で確定します（改行は Shift+Enter）。
  2. ノードにマウスを乗せると、四辺に小さな円（ポート）が現れます。右のポートをつかんで 何もない場所へドラッグすると、標準間隔だけ離れた新しいノードが作られ、接続されます。これを繰り返せば、整列したフローが完成します。
  3. 分岐が必要なら ひし形（D）を置き、ポートを別のノードへドラッグして接続したあと、コネクタをダブルクリックして Yes/No のラベルを入力します。
  4. 右パネルで塗りの色を選び、必要に応じて フェーズバンド で区間をまとめます。
  5. 書き出し → SVG (Export → SVG / 내보내기 → SVG) で保存すれば、原稿エディタや Illustrator、PowerPoint でそのまま使えます。

図形とテキスト

図形 13 種：角丸長方形（処理）、長方形、開始/終了（カプセル形）、ひし形（判断）、楕円、平行四辺形（入出力）、円柱（データ）、六角形（準備）、矢印ブロック（段階）、三角形、星（強調）、文書、クラウド（外部システム）。選択した後、右パネルの図形グリッドでいつでも別の形に変えられます。

  • 移動：ドラッグ。他のノードの中心線・端と揃うとピンクのガイドが現れ、磁石のように吸着します。自由に置くには Alt を押しながらドラッグします。
  • サイズ：選択後に 8 つのハンドルをドラッグするか、パネルの W/H に数値を入力します。
  • 文字：ダブルクリック（または Enter）で編集。パネルで文字サイズ・太字・左揃え（箇条書きに便利）・文字色 (Text color / 글자 색) を設定します。
  • テキスト（T）：図形なしで文字だけを置きます。パネル文字 a、b や図のタイトルに使います。
  • 複製 Ctrl+D、削除 Delete、微調整 は矢印キー（Shift で 10 倍）。

コネクタ

作り方は 3 通りです。① ノードのポートを別のノードへドラッグ、② C ツールで始点ノード → 終点ノードをクリック、③ 手描き（P）で 2 つのノードの間に線を引く。

  • 経路 (Route / 경로)：直角（既定）(Orthogonal / 직각)・直線 (Straight / 직선)・曲線 (Curved / 곡선)。直角の経路は両側が対称になるよう中央で折れ、線を選択すると現れる丸いハンドルをドラッグして折れる位置を動かせます。自動経路 (Auto route / 자동 경로) で自動に戻ります。
  • 矢印：始点・終点それぞれに なし / 塗り / 開き / 点 から選択。方向反転 (Reverse / 방향 반전) で始点と終点を入れ替えます。
  • 再接続：線を選択すると両端に四角いハンドルが現れます。別のノードへドラッグするか、何もない場所に置いて自由端点にできます。
  • ラベル・破線・色・太さ：パネルで設定。複数の線を同時に選択すると一度に適用されます。
  • 長さの統一 (Equalize length / 길이 통일)：複数のコネクタを選択し、px の値を入れて適用すると、各終点ノードが始点ノードから同じ距離に移動します。直線化 (Straighten / 직선화) をオンにすると中心線まで揃い、折れがなくなります。
線がわずかに折れるとき 2 つのノードの中心の高さが数 px ずれているためです。片方を少しドラッグしてピンクのガイドに吸着させるか、2 つを選択して「上下中央」揃えを押してください。

整列・間隔・グループ

Shift+クリック、または何もない場所からのドラッグ（範囲選択）で複数の要素を選びます。2 つ以上選択すると、パネルに整列ツールが表示されます。

  • 整列 左 / 左右中央 / 右 / 上 / 上下中央 / 下
  • 左右に均等 · 上下に均等 (Distribute H · Distribute V / 가로 균등 · 세로 균등) — 両端はそのままで、間の間隔だけを揃えます
  • 間隔の固定 (Fixed gap / 간격 고정) — 入力した px 間隔で順番に並べ直します（「横に適用」(Apply H / 가로 적용) / 「縦に適用」(Apply V / 세로 적용)）。ノード間のコネクタの長さがすべて同じになります
  • 幅を揃える · 高さを揃える (Match width · Match height / 너비 길이 맞춤 · 높이 길이 맞춤) — 最初に選択した図形の幅または高さに、他の図形を合わせます
  • グループ Ctrl+G — 以後、1 つをクリックするとグループ全体が選択され、一緒に移動・削除されます。コネクタもグループに入れられます。解除は Ctrl+Shift+G。

フェーズバンド・パネルラベル

バンドは、複数のノードを 1 つの区間にまとめる淡い背景です。ツールバーの点線の四角アイコンで置き、サイズを調整してください。バンドを動かすと、中のノードも一緒に動きます。バンド内の何もない場所からドラッグすると、バンドではなく内側の要素が範囲選択されます（バンド自体は枠の近くやラベル部分をつかんで動かします）。

  • ラベル：先頭の 1 文字の後に半角スペースを 2 つ入れると（a Sample collection）、先頭の文字がパネル文字として太く大きく表示されます。
  • 背景：塗りのパレットから選択。角：角張り / 8 / 16 / 28 px。枠線：なし / 実線 / 破線。
  • スイムレーン：縦長のバンドを並べると、担当者・部署ごとのプロセス図になります（レポート用テンプレート「承認プロセス」参照）。

手描き認識

P を押してマウスやペンでざっと描くと、規格の図形に変わります。閉じた形は角の数と傾きによって長方形・ひし形・楕円・カプセル形として、開いた線はコネクタとして認識されます。2 つのノードの間に線を引くと、その 2 つをつなぐコネクタになります。

認識直後に現れる小さなポップアップで別の図形（処理・長方形・開始/終了・判断・楕円・コネクタ）に切り替えるか、最後のアイコンで手描きの原形をそのまま残せます。認識はルールベースのため複雑な絵は正確でない場合があり、六角形や星などの図形は認識しません。

画像・アイコンライブラリ

ツールバーの画像アイコン（またはパネルの「画像・アイコンのアップロード」(Upload image · icon / 이미지 · 아이콘 업로드)）で PNG / JPG / SVG をアップロードすると マイ画像図形 (My image shapes / 내 이미지 도형) に保存され、以後はクリック → キャンバスをクリックでいつでも配置できます。配置した画像は通常のノードと同じようにポートで接続し、サイズを変え、ダブルクリックで下にキャプションを付けられます。

  • 背景の除去 (Remove background / 배경 제거)：画像を選択し、強さ 弱 / 中 / 強 (Low / Medium / High / 약 / 중 / 강) のいずれかを押すと、端とつながった単色の背景（白など）が透明になります。結果が気に入らなければ別の強さを押すか、元画像 (Original / 원본) に戻します。背景を消した版は「この版をライブラリに追加」(Add this version to the library / 이 버전을 라이브러리에 추가) で別に保存できます。写真のように背景が均一でない場合はうまく消えません。
  • 単色化 (Monochrome / 단색화)：グレースケールにして論文の図のトーンに合わせます。枠ボックス (Border box / 테두리 상자)：他のノードと同じ枠線で囲みます。
  • 大きな写真は自動的に 640 px 以下に縮小して保存します。ライブラリから削除するには Shift+クリック。
  • ライブラリはこのブラウザにのみ保存されます。図そのものは JSON/SVG に画像が含まれて書き出されるので、他の PC でも開けます。

カラーパレット

図形を選択すると、パネルに 塗り (Fill / 채움)・枠線 (Border / 테두리)・文字色 (Text color / 글자 색) のパレットが別々に表示されます。既定の色は、色覚多様性や白黒印刷でも区別しやすい Okabe–Ito 系を調整したものです。色にマウスを乗せると名前と HEX コード（例：#2F6DB5）が表示されます。

  • 塗り：1 行に 34 色 — 白、グレー 3 段階、そして 10 色相（グレー・青・青緑・緑・黄・橙・赤・紫・紺・ピンク）の淡い / 中間 / 濃い段階。濃い塗りを選ぶと文字が自動的に白になります。
  • 枠線：なし（点線の空欄で表示）と 10 色。「なし」はすべての図形に使えます。
  • 文字色：白と 10 色。自分で選んだ文字色は、自動の白より優先されます。
  • 色の追加：各パレットの末尾の + を押すと、おすすめの 24 色、カラーピッカー、HEX 入力欄（#RRGGBB）が現れます。追加した色は そのパレットにだけ 入り、このブラウザに保存されます。削除するには Shift+クリック。
  • 図全体の既定の線・文字の色は、何も選択していない状態で 図の規格 → 既定の線・テキストの色 (Figure style → Default line · text color / 그림 규격 → 기본 선 · 텍스트 색) から変更します。
おすすめ 1 つの図で使う強調色は 2〜3 色までにし、残りは白・グレーに。色を意味（データ / 処理 / 判断 / 結果）にだけ対応させると読みやすくなります。

テンプレート

ファイル → テンプレート (File → Templates / 파일 → 예제) から開き、内容だけを書き換えて使ってください。テンプレートの文字は一部が韓国語、一部が英語です。

書き出し・保存

  • SVG：ベクター。学術誌への投稿、Illustrator/Inkscape での編集、Word・PowerPoint への挿入に最適です。グリッドや選択表示は含まれません。
  • PNG：キャンバスの 3 倍の解像度（幅 1200 px のキャンバス → 3600 px、幅 30 cm で約 300 dpi）。システムフォント（Arial など）で描画されます。
  • JSON：編集可能な元データ。他の PC や同僚に渡すときに使い、ファイル → JSON を開く (File → Open JSON… / 파일 → JSON 불러오기) で開きます。
  • SVG コードのコピー (Copy SVG code / SVG 코드 복사)：ダウンロードが制限された環境で、クリップボードにコピーして .svg ファイルとして保存できます。
  • 自動保存：作業はブラウザに自動保存され、次に開くと続きから始められます。ブラウザのデータを消すと失われるので、大切な図は JSON で保管してください。

他のサイトへの埋め込み

Workflow-assist はビルド不要で index.html 1 ファイルで動作するため、他のウェブサイトに iframe で埋め込み、JavaScript API（postMessage）で文書を読み込んだり取り出したり、SVG を受け取ったりできます。サイトの技術（React、Vue など）は問いません。

  • 動作するサンプル：embed-example.html（同じフォルダで開けばすぐ動きます）
  • API 仕様と文書（JSON）形式：DEVELOPER.md（韓国語）

よくある質問

学術誌に投稿するときのおすすめ設定は？

Nature プリセット、文字サイズ 11〜12 px、キャンバス幅 1200 px（2 段幅の図の場合）で描き、SVG で書き出してください。ほとんどの学術誌はベクター（SVG/PDF/EPS）を好み、ラスターが必要なら 3 倍の PNG で十分です。

PNG で書き出すとフォントが変わります。

PNG はブラウザ内部でシステムフォントを使って描画します。フォントを正確に保つには、SVG で書き出してから Illustrator・Inkscape などで PNG/PDF に変換してください。

コネクタが他のノードを横切ります。

線を選択して丸いハンドルをドラッグし折れる位置を動かすか、経路を「曲線」に変えるか、始点・終点のポートを別の辺に再接続してください（端のハンドルをノードの希望する辺の近くに置くと、その辺のポートに吸着します）。

複数の図を管理したいです。

図ごとに JSON で保存しておき、必要なときに開いてください。自動保存は最後の作業 1 つだけを保持します。

別の PC やブラウザに移したいです。

図は 書き出し → JSON で保存し、新しい環境で ファイル → JSON を開く で開きます。追加した色と画像ライブラリはブラウザごとに保存されるため移せません（図の中に配置した画像は JSON に含まれます）。
